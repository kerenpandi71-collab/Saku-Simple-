# Saku Simple

**A minimal Android launcher focused on clarity, speed, and everyday usability.**

Saku Simple is the home for a lightweight launcher project in the Saku family. The goal is to keep the home screen clean and make opening apps straightforward, without unnecessary visual clutter.

> **Project status:** Initial repository scaffold. Application source code, supported Android versions, screenshots, and downloadable builds have not been added yet.

## Project goals

- **Minimal by design:** a focused home-screen experience with clear visual hierarchy.
- **Responsive UI:** layouts that remain usable across different screen sizes and display densities.
- **Reliable launching:** predictable app discovery and app-opening behavior.
- **Maintainable code:** small, understandable components and documented changes.
- **Privacy-conscious defaults:** avoid unnecessary permissions and dependencies.

These are project goals, not claims that features are already implemented.

## Reporting issues

When reporting a problem, include:
- Device model and Android version.
- The steps that reproduce the issue.
- What you expected to happen and what happened instead.
- A relevant, redacted log or screenshot when useful.

Do not include passwords, access tokens, or other private information in issue reports.

## Contributing

Keep changes focused, explain the reason for a change, and include build/test results when available. Avoid adding permissions or dependencies unless they are necessary and their purpose is documented.
